# 🧭 Maze Solver using BFS

A Python implementation of the Breadth-First Search (BFS) algorithm to solve virtual mazes and compute the shortest path.

## 🎯 Features

- Implements BFS from scratch using queue and visited set
- Visualizes path through terminal or graphical output (based on project)
- Designed to handle mazes of various sizes and complexities
- Includes a video demo for better understanding

## 🛠️ Technologies

- Python
- Basic data structures (Queue, Set, 2D arrays)

## 🚀 How to Run

```bash
python Vatsal_EE23B084_bfs.py
```
